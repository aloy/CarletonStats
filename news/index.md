# Changelog

## CarletonStats 2.3

- [`boot()`](https://aloy.github.io/CarletonStats/reference/boot.md) and
  [`permTest()`](https://aloy.github.io/CarletonStats/reference/permTest.md)
  now accept logical, factor, and character response variables with
  exactly two levels. A new `success` argument specifies which level is
  coded as 1 (proportion). A message confirms the coding chosen.

- [`bootPaired()`](https://aloy.github.io/CarletonStats/reference/bootPaired.md)
  computed the paired difference as `x - y`, inconsistent with
  [`permTestPaired()`](https://aloy.github.io/CarletonStats/reference/permTestPaired.md)’s
  `y - x`; both now use `y - x`, and
  [`permTestPaired()`](https://aloy.github.io/CarletonStats/reference/permTestPaired.md)’s
  printed group means, which were mislabeled, now show the correct name
  next to each mean.

- [`permTestCor()`](https://aloy.github.io/CarletonStats/reference/permTestCor.md)
  and
  [`permTestPaired()`](https://aloy.github.io/CarletonStats/reference/permTestPaired.md)
  had a `seed` argument that was silently ignored, making results
  non-reproducible. The `seed` argument now correctly sets the random
  seed before the permutation loop.

- Minimum R version is now declared as R (\>= 3.5.0) and minimum ggplot2
  version as 3.3.0 in `DESCRIPTION`.

## CarletonStats 2.2

CRAN release: 2023-08-22

- The `boot*()` functions now return the bootstrap statistics as a
  `carlboot` object, which has `print`, `plot`, `summary`, and `confint`
  methods.

- The `permTest*()` functions now return the bootstrap statistics as a
  `carlperm` object, which has `print`, `plot`, and `summary` methods.

- Additional arguments were added to the `boot*()` and
  `permTest*() functions:`xlab`,`ylab`,`title`,`seed\`.

- Some arguments were deleted from the `boot*()` functions: `legend.loc`
  (just use ggplot2 theme if needed), `hist.title` (now use `title`)

- All plots generated by the `boot*()` and `permTest*()` functions are
  now rendered via ggplot2.

## CarletonStats 2.1

CRAN release: 2023-05-01

- Added a new bootstrap function:
  [`bootSlope()`](https://aloy.github.io/CarletonStats/reference/bootSlope.md)

- Added two new permutation test functions:
  [`permTestSlope()`](https://aloy.github.io/CarletonStats/reference/permTestSlope.md)
  and
  [`permTestAnova()`](https://aloy.github.io/CarletonStats/reference/permTestAnova.md)

- Added formula syntax for \`\`

- Added a `NEWS.md` file to track changes to the package.
