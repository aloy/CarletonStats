# Correlation demonstration

For a given `r`, create a scatterplot of two variables with that
correlation.

## Usage

``` r
corDemo(r = 0)
```

## Arguments

- r:

  a number between -1 and 1. Enter any number r, \\latex\\, to exit the
  interactive session\[

## Details

Demonstrate the concept of correlation by inputting a number between -1
and 1 and seeing a scatter plot of two variables with that correlation.
Once you invoke this command, you can continue to enter values for r.
Type any number \\latex\\) to exit.
